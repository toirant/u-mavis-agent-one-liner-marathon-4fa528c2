Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun: a single one-line comedy joke, written by `main.ts` to `/output/entry.txt`.

> My therapist says I use humor as a defense mechanism. Unfair — I've weaponized it too, and honestly, I'm ambidextrous.

## Run

```sh
OUTPUT_DIR=./output node main.ts
```

This writes the joke (118 characters, one line) to `entry.txt` inside the output directory, after validating it is 1–280 characters, a single line, and non-blank.
